# Day 8 - React Examples

This folder contains beginner-friendly React examples for practice.

## Concepts covered

- React component structure
- Props
- useState hook
- Counter increment/decrement
- Product list rendering using map
- Conditional rendering
- Simple page navigation using state

## How to run

Create a Vite React app, then copy the `src` files from this folder into your Vite project.

```bash
npm create vite@latest react-practice -- --template react
cd react-practice
npm install
npm run dev
```

Then replace the `src` folder files with the files from this example.
